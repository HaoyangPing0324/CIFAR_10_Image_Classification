# 使用 PyTorch 进行 CIFAR-10 图像分类

## 项目来源
苏州大学未来科学与工程学院《人工智能》课程
任课老师：吴洪状

## 任务描述：
CIFAR-10 数据集包含 10 类彩色图像，每类 6000 张，总共 60000 张图像（50000 张训练集，10000 张测试集）。请使用 PyTorch 训练两个分类模型：

1、全连接神经网络：使用多个全连接层（Fully Connected, FC）完成分类任务。
2、卷积神经网络：使用卷积层（Convolutional Layer）完成分类任务。

## 具体要求：

### 数据处理
- 使用 torchvision.datasets.CIFAR10 加载数据集。
- 进行归一化预处理（将像素值缩放到 [0,1] 或 [-1,1]）。
- 采用 torch.utils.data.DataLoader 进行批量加载，并可视化部分样本图像。

### 模型构建
#### MLP 模型：
- 需要包含至少 3 层全连接层（可选BN层）。
- 使用 ReLU 作为激活函数。

#### CNN 模型：
- 至少包含 2 个卷积层（可选池化层、BN层）。
- 使用 ReLU 作为激活函数。

### 训练
- 采用交叉熵损失函数（torch.nn.CrossEntropyLoss）。
- 使用 SGD 或 Adam 进行优化（torch.optim.SGD / torch.optim.Adam）。
- 训练至少 10 轮（Epochs），并实时绘制损失曲线和准确率曲线。

### 测试与可视化
- 计算模型在测试集上的分类准确率，并绘制混淆矩阵。
- 随机选取部分测试集样本，进行预测，并可视化预测结果与真实标签对比。

### 可视化部分
- 显示部分 CIFAR-10 数据集的样本图像。
- 绘制训练过程中的损失变化曲线和准确率变化曲线。
- 在测试集上绘制混淆矩阵，分析模型的分类情况。
- 选取测试集中部分图像，展示模型的预测结果，并与真实标签进行对比。
